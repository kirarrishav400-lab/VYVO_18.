# VYVO

A frontend-first social-media website prototype.

## Run
Open `index.html` in a modern browser. No build step is required.

## Included
- Responsive landing page
- Demo login/signup
- Home feed and stories
- Likes, saves, comments and share demo
- Explore grid
- Reels UI
- Create-post UI with local file selection demo
- Profile
- Notifications
- Messaging UI
- Settings
- Mobile bottom navigation
- Reduced-motion support
- localStorage demo session

## Important
This is a frontend prototype. Authentication, media uploads, permanent posts, real-time messaging, and database storage require a secure backend.

Do not put API secrets in `script.js`.

## Future app conversion
The HTML/CSS/JS structure is intentionally separated so it can later be wrapped in an Android WebView/PWA or migrated to a native/cross-platform frontend.
